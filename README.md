# Java Learning

Hands-on Java practice organized by topic. Every concept has small, runnable programs, each with its own `Main.java` so it can be executed in isolation.

## Contents

### Object-Oriented Programming (`oop/`)

| Topic | What it covers |
|---|---|
| `01-classes-objects` | Defining classes and creating objects (HotelRoom example) |
| `02-constructors` | Default, parameterized, copy and private constructors, plus constructor interview questions |
| `03-this-keyword` | `this` with instance variables, constructors, methods and constructor chaining |

More topics (inheritance, polymorphism, collections, streams, concurrency) will be added over time.

## How to run

```bash
cd oop/02-constructors/01_Default_Constructor
javac *.java
java Main
```

Requires JDK 17 or newer.

## Why this repo

I use it to build strong Java fundamentals for backend development and to revise core concepts for interviews.
